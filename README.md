# 🐦 Flappy Bird – Java

A simple **Flappy Bird clone built using Java**.
The project recreates the classic gameplay where the player controls a bird and tries to pass through pipes without hitting them.

## 🎮 Features

* 🐦 Bird movement and gravity
* 🟩 Moving pipes
* 💥 Collision detection
* 🏆 Score tracking
* 🔄 Game restart functionality
* 🎮 Simple keyboard controls
* 🖥️ Java-based GUI

## 🛠️ Technologies Used

* **Java**
* **Java Swing / AWT**
* **Object-Oriented Programming (OOP)**

## 🎯 How to Play

* Press **Spacebar** to make the bird jump.
* Avoid hitting the pipes.
* Try to achieve the highest possible score.
* If you collide with a pipe or the ground, the game ends.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/raj969961/FlappyBird-Java.git
```

### 2. Open the project

Open the project in **IntelliJ IDEA**, **VS Code**, or any Java-supported IDE.

### 3. Run the game

Run the main Java class to start playing.
